# Accessible E-Commerce Store

A responsive and accessible e-commerce storefront demonstrating authentication simulation, REST API integration, product management, shopping cart functionality and persistent client-side state.

## Features

- Authentication simulation
- Product catalog
- REST API integration
- Search and sorting
- Shopping cart
- Dynamic CRUD operations
- localStorage persistence
- Responsive design
- Accessible HTML
- Error handling

## Technologies

- HTML5
- CSS3
- JavaScript ES Modules
- REST API
- localStorage
