# Accessible Dashboard

## Task 2 – Responsive Design Tokens & Mobile-First CSS Architecture

### Features

- Design token system using CSS variables
- Responsive mobile-first layout
- Breakpoints at 320px, 768px, 1024px and 1440px
- Responsive dashboard grid
- Glassmorphism effects
- Soft shadows and hover transitions
- Light and dark theme variables
- Mobile-friendly navigation and sidebar
- Zero horizontal page scrolling on mobile
